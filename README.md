# DockFlow
PWA mobile (React + Vite + Motion) de suivi des livraisons d'un dépôt. Données de démo fictives, stockées localement (IndexedDB).
- `npm install` puis `npm run dev` (développement) ou `npm run build` (produit `dist/`)
- GitHub Pages : `VITE_BASE=/dockflow/ npm run build`
- iPhone : Safari → Partager → Sur l'écran d'accueil.
